# ChatBrief

ChatBrief 是一个本地微信聊天整理工具，帮助你把群聊和好友对话整理成可核对、可导出的总结与洞察。

## 下载

前往 [Releases](https://github.com/Avery-lotus/ChatBrief/releases) 下载最新版 Windows 压缩包。

下载后解压，运行 `WeChatSummary.Desktop.exe` 即可使用。

## 主要功能

- 微信 4.1.9.57 本地数据读取
- 粘贴或导入聊天文本
- 群聊与好友聚焦分析
- 同类对象对照
- 洞察统计、本地提问和原文证据定位
- Markdown 导出

## 隐私说明

ChatBrief 面向个人本地使用。聊天数据、配置和 API Key 默认保存在用户本机，请不要把个人聊天数据或 API Key 提交到公开仓库。
